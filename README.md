# 人间烟火 · 中国式人生经营模拟

一款「从 18 岁开始，做选择、讨生活、盘生意」的中文人生经营游戏。
网页端 + 手机端（PWA，后续可打包成 App）。

## 现在能玩到什么

- **捏人开局**：姓名 / 性别 / 出身（省会 · 县城 · 农村）/ 是否上大学
- **月回合**：学习、上班、在校兼职、健身、社交应酬、休息
- **八项状态**：智力、体质、颜值、情商、健康、心情、人脉、名气
- **盘生意**：网店 / 奶茶店 / 便利店 / 小餐馆 / 小工厂，含房租、员工、原料成本
- **经营操作**：促销、员工培训、装修升级、招人裁人、调价
- **随机事件**：亲戚借钱、公司加班、售楼处电话、相亲、加盟招商、体检报告、直播风口、父母生病、股市、涨租、合伙人做假账
- **结局**：60 岁总结算，按净资产评级（衣锦还乡 / 小有成就 / 安稳一生 / 平平淡淡 / 一地鸡毛）
- **自动存档**：localStorage，刷新不丢
- **房间模式（v0.2 开发中）**：等距小屋，六项需求实时衰减，角色自己走去用家具，倍速/暂停、建造买家具、上班赚钱

## 房间模式怎么玩

开局页点「先进屋看看」。

- 点家具 → 角色自己寻路过去使用（床补精力、冰箱补饱腹、淋浴补清洁、电脑/电视补娱乐、手机补社交、马桶/沙发补舒适）
- 需求条见底会难受。🧠 开着「自由意志」，角色会自己去找东西用；关掉就得你手动点
- 🛒 建造：选一件家具，再点地砖放下去
- ⏸ / 1× / 2× / 4×：1× 时 1 真实秒 = 1 游戏分钟
- 「去上班」直接结算 8 小时工资，代价是各项需求大幅下降

## 开发

```bash
npm install
npm run dev      # 本地开发，手机同网段可直接访问
npm run build    # 类型检查 + 生产构建
```

## 结构

```
src/
├── game/              # 纯逻辑层，不依赖 React，可单独测试
│   ├── types.ts       # 全部类型
│   ├── rng.ts         # 确定性随机数（同 seed 同结果）
│   ├── effects.ts     # 数值变更与格式化
│   ├── content.ts     # 生意类型表 + 事件库（内容都在这里加）
│   └── engine.ts      # 开局、行动、月结算、经营、事件、结局
├── components/        # 表现层
├── sim/               # 房间模式：实时生活模拟（纯逻辑 + 等距渲染）
│   ├── sim.ts         # 网格、需求、寻路、家具交互、自由意志
│   └── SimScreen.tsx  # SVG 等距渲染 + 倍速循环 + 建造面板
└── styles.css         # 设计系统（米纸底 / 朱红 / 金）
scripts/smoke.ts       # 无浏览器冒烟测试：连跑 12 局验证数值不发散
scripts/sim-smoke.ts   # 房间模式冒烟测试：跑 2.6 个游戏日验证需求不越界
```

## 冒烟测试

```bash
npx esbuild scripts/smoke.ts --bundle --platform=node --format=esm --outfile=.tmp/smoke.mjs
node .tmp/smoke.mjs
```
